# Board Exam Demo (Super Simple)

## What you will show
1. Open the app (phone or web link)
2. Register a user
3. Login as user
4. Submit a complaint
5. Submit a service request
6. Login as admin
7. See all complaints + update status
8. See all service requests + mark resolved
9. Post a notice + show it on notice board

## Demo accounts
- User: register any email
- Admin: register your admin email, then in MySQL run:
  UPDATE users SET role='admin' WHERE email='youradminemail@example.com';

## If internet fails
Record a 30–60 sec screen recording of steps 1–9 as backup.
